Plano de Desenvolvimento Profissional — Rumo a Desenvolvedor(a) Front-end

Perfil de partida: conhecimento em lógica de programação, ensino técnico concluído, graduação em Ciência da Computação em andamento.

Abordagem do plano: tratado como se você estivesse começando do zero na trilha específica de front-end, para não deixar lacunas de fundamentos.

01. Meta Smart

Em até 6 meses, tornar-me capaz de atuar como Desenvolvedor(a) Front-end Júnior, dominando HTML5, CSS3, JavaScript ES6+, Git/GitHub e React, com um portfólio de no mínimo 4 projetos publicados (incluindo 1 projeto full com consumo de API e 1 com TypeScript), e aplicar para pelo menos 15 vagas ou processos seletivos até o final do mês 6.

Critério Como se aplica
Específica: Foco em uma stack definida (HTML, CSS, JS, React, Git, com TypeScript como diferencial) e um objetivo de carreira claro (vaga júnior ou primeiro projeto freelance).
Mensurável: Número de cursos concluídos, projetos publicados, commits no GitHub, candidaturas enviadas.
Atingível: Você já tem lógica de programação e vivência acadêmica em CS — isso acelera a curva de aprendizado em relação a alguém 100% leigo.
Relevante: Front-end segue com alta demanda no mercado brasileiro em 2026, com React como padrão de mercado e TypeScript virando exigência crescente até para vagas júnior.
Temporal: Prazo de 6 meses, dividido em ciclos mensais com entregas específicas.

02. Por que essa stack (validado com dados de mercado atuais)

Pesquisando o cenário de 2026 no Brasil, alguns pontos importantes para direcionar o esforço:

  • React continua sendo o padrão da indústria no Brasil, é a escolha mais segura para conseguir vagas, especialmente júnior.
  • TypeScript deixou de ser "diferencial" e virou exigência. A falta de TS é hoje uma das principais lacunas que travam desenvolvedores juniores em processos seletivos, por isso incluí no roadmap.
  • Next.js (framework em cima do React) se consolidou como padrão em vagas mais atuais, então vale conhecer o básico depois de dominar React puro.
  • Git/GitHub e Figma (para implementar designs) aparecem como habilidades esperadas mesmo em vagas juniores.
  • Ferramentas de IA (Copilot e similares) já fazem parte do fluxo de trabalho, vale aprender a usá-las bem desde já, mas sem depender delas para aprender fundamentos.

03. Roadmap - 6 meses, por etapas

    Mês 1 - Fundamentos Web (HTML + CSS)

  • HTML5 semântico, formulários, acessibilidade básica
  • CSS3: Flexbox, Grid, variáveis CSS, media queries (responsividade)
  • Git e GitHub: comandos básicos, versionamento, primeiro repositório
    • Entrega do mês: 1 landing page responsiva publicada no GitHub Pages

    Mês 2 - JavaScript fundamentos

  • Lógica em JS: variáveis, funções, arrays, objetos, DOM
  • Manipulação de eventos, formulários dinâmicos
  • ES6+: arrow functions, destructuring, spread/rest, módulos
    • Entrega do mês: 1 mini app interativo (to-do list, calculadora, etc.)

    Mês 3 - JavaScript avançado + assincronismo

  • Promises, async/await, fetch API, consumo de APIs REST
  • Manipulação avançada do DOM, LocalStorage
  • Introdução a TypeScript (tipagem básica)
    • Entrega do mês: app que consome uma API pública (clima, filmes, etc.)

    Mês 4 - React (fundamentos)

  • Componentes, props, state, hooks (useState, useEffect)
  • Roteamento com React Router
  • Boas práticas de organização de projeto
    • Entrega do mês: SPA em React com rotas e componentes reutilizáveis

    Mês 5 - React avançado + TypeScript + Tailwind

  • React + TypeScript juntos
  • Context API ou gerenciamento de estado simples (Zustand, por exemplo)
  • Tailwind CSS para estilização rápida
  • Consumo de API real com tratamento de loading/erro
    • Entrega do mês: projeto completo (CRUD com API, React + TS + Tailwind)

    Mês 6 - Portfólio, Next.js básico e mercado

  • Introdução a Next.js (server components, roteamento moderno)
  • Montagem do portfólio (site próprio mostrando os projetos)
  • Ajuste de currículo e LinkedIn voltados a front-end
  • Prática de entrevistas técnicas e lógica (ex: exercícios de algoritmos leves)
    • Entrega do mês: portfólio no ar + candidaturas enviadas

04. Onde estudar

Gratuitas / referência mundial:

  • MDN Web Docs - documentação oficial de HTML/CSS/JS, referência para consultar sempre
  • freeCodeCamp - currículo completo e gratuito, ótimo para HTML/CSS/JS/React
  • The Odin Project - trilha completa e gratuita, muito respeitada internacionalmente
  • JavaScript.info - o melhor material gratuito para JS profundo

Brasileiras (conteúdo em português, bom para contexto de mercado local):

  • Origamid - referência forte em HTML, CSS e JavaScript com foco prático
  • Rocketseat - trilhas focadas em React/Next.js, muito usada por quem busca vaga no Brasil, tem comunidade ativa
  • Alura - cursos estruturados por trilha (front-end), bom para quem gosta de formação guiada, já que sua faculdade é em CS eles têm parceria com algumas instituições

Prática e portfólio:

  • Frontend Mentor - desafios reais de layout para praticar HTML/CSS/JS/React com base em designs profissionais (ótimo para portfólio)
  • GitHub - hospedar todos os projetos, usar desde o primeiro dia

Sugestão de uso: escolha uma plataforma principal por etapa (evite pular entre muitas ao mesmo tempo) e use o Frontend Mentor e o freeCodeCamp como prática paralela constante.

05. Hábitos diários

1. Codar por pelo menos 45–60 minutos todos os dias (mesmo nos dias corridos de faculdade). Consistência diária vale mais que maratonas no fim de semana — é o que fixa lógica e sintaxe na memória.
2. Fazer 1 commit no GitHub por dia. Não importa se é pequeno. Isso cria o hábito de versionamento profissional e, como efeito colateral, gera um histórico de contribuições visível para recrutadores.
3. Ler ou assistir 1 conteúdo técnico curto por dia (artigo, thread, vídeo de 10–15 min) sobre front-end — pode ser sobre uma técnica nova, um bug comum, ou tendência de mercado. Isso mantém você atualizado sem virar estudo formal.
